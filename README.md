## 🚀 Instant Vercel Deployment

### Option A: Via GitHub (Recommended)
1. Push this repository to your GitHub account:
   ```bash
   git add .
   git commit -m "feat: hipuku.dev inspired dark devops portfolio with gmail redirect"
   git push origin main
   ```
2. Go to **[vercel.com/new](https://vercel.com/new)**.
3. Import your repository. Vercel will automatically detect `index.html` and `vercel.json`.
4. Click **Deploy**. Your site will be live worldwide in seconds!

### Option B: Via Vercel CLI
```bash
npm i -g vercel
vercel
```
